## v1.4.0 修了什么

上一版 v1.3.0 在真机上能播出来了，但出现了「反复重载、按确定键没反应、状态显示脚本异常、白色大圆环糊屏」。
自检条把真实状态打印出来后，定位到**全部是 v1.3.0 自己加的几层「保险」互相打架**，与电视内核、网络无关：

| # | 现象 | 真因 | v1.4.0 修法 |
|---|---|---|---|
| 1 | 1 分钟内反复回到「正在连接」、画面闪回白色圆环 | 注入层 20s 切源 + 原生 25s 切源 + `onPageStarted` 重置 `everPlaying`，三者互相点火：切源触发重载 → 重置 → 计时归零 → 又切源 | **删除所有自动切源 / 自动 reload**；`everPlaying` 一旦为 true 永不被重载重置；看门狗只观察、只提示 |
| 2 | 按确定键调不出频道和分类 | 确定键在 `stage==='failed'` 时被写成整页 reload；注入未就绪时转发用 `&&` 短路静默吞掉按键；自检条还写着「按确定键可重试」把用户往坑里引 | **确定键永远第一优先打开选台面板**；注入未就绪给「界面加载中」可见反馈；重试改到数字键 **9** |
| 3 | 状态一直显示「脚本异常」，但画面其实在播 | 全局 error 钩子把央视频网页自身的无害异常（`a0b is not defined @<uuid>:1`）当成软件致命错误上报，并强制钉住自检条 | 只上报属于 LinkTV 注入层的异常；网页自身异常直接忽略；error 不再刷主状态、不再强制弹条 |
| 4 | 巨大的白色圆环播放按钮糊满屏 | 视频未就绪时网页的 poster / 加载占位图被 `object-fit:cover` 放大；重注入重建 UI 时新遮罩默认隐藏导致露底 | `clean()` 清除 `poster` 并压黑底；**待播遮罩默认开启**、带 LinkTV 品牌；出过画面后掉线立即重新盖住（只等待、不重载） |

**核心原则：只留一个观察哨，绝不自动导航。** 唯一的整页重载入口是用户主动按数字键 9。

## 遥控器操作

| 按键 | 作用 |
|---|---|
| **确定 / OK** | 打开选台面板；面板内选中频道即播放 |
| ▲ ▼ | 全屏时换台（分类内循环）；面板内选频道 |
| ◀ ▶ | 全屏时换分类；面板内 ◀ 焦点到分类栏、▶ 切分类 |
| 菜单 / ★ | 收藏 / 取消收藏（提示在右上角，2 秒淡出） |
| 返回 / Esc | 收起面板；全屏时连按两次退出 |
| **9** | 手动重新加载当前频道（唯一重载入口，网络异常时用） |
| **0** | 显示 / 隐藏左下角自检条 |

## 自检条说明

左下角半透明条是原生 `TextView`，网页全黑也能看见，播放正常 6 秒后淡出：

```
LinkTV v1.4.0 · 电视版自检
状态：播放中
网页：www.yangshipin.cn   注入：已就绪 · 清理×12   画面：已出画面
内核：Chrome 83.0.4103.120 | MSE 支持 | WASM 支持
状态正常 · 按 [0] 隐藏/显示自检 · [9] 重新加载
```

- **状态：播放中 / 画面：已出画面** = 正常
- 若长时间「等待画面」，先按 **9** 重载；仍不行检查电视网络
- 若 `MSE 不支持` / `WASM 不支持`，是这台电视固件内核能力不足，官方播放器可能起不来（v1.4.0 已实测 Chrome 83 + MSE/WASM 可正常播放）

## 技术方案

- WebView 全屏打开央视频官方直播页 `https://www.yangshipin.cn/tv/home`，由官方网页负责鉴权 / 拉流 / 播放
- 注入层 `clean()` 按 DOM 路径隐藏网页浮层，只留 `<video>` 钉成 `fixed` 全屏（不写死网页 class）
- 频道表 **CCTV 全系列 18 + 31 省级卫视 = 49 台**，官方 `pid` 直连；换台优先点击页面内频道元素（不刷新），失败降级 `?pid=` 导航（4 秒节流）
- 桌面 UA 用系统真实 Chrome 版本（不虚报）；`dispatchKeyEvent` 前置拦截遥控器按键
- 原生自检覆盖层 + 轮询确认注入（未就绪自动重注入最多 8 次）
- 官方 EPG 节目单，失败降级为「正在直播 · 频道名」
- **不含任何 m3u8 直链，不导入 M3U，不需用户填写任何源**

## 已知限制

- 依赖央视频官方网页，官方改版可能让清浮层 / 换台失效
- 官方播放器需 Chrome 内核 70+（wasm + MSE），过旧会提示
- 异地 / 运营商可能访问不了央视频；按 **9** 可手动重载
- 换台约需数秒，期间显示品牌待播遮罩（不再是网页白色圆环）
- 各品牌电视 / 盒子的 WebView 存在差异，沙箱无法替代真机实测

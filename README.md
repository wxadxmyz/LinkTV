# LinkTV · 安卓电视直播

**当前版本：v2.1.0（原生播放器版 · 触屏 / 极简遥控器适配 · 画面自动铺满 · 干净官方源）**

面向 Android TV / 盒子 / 手机的电视直播应用。打开即全屏播放，遥控器或触屏都能操作，无需登录、无需自己填直播源。

> 直播源以**逐条验证有视频轨**的官方/聚合流为主（各省市台官方 CDN + 验证过的聚合源），非官方授权，仅供自用；线路可能失效，应用内已用多备线兜底。v2.1.0 已剔除全部「只有声音没画面」的纯音频流与失效内网源。

## 下载

- 正式版（带版本号）：`https://github.com/wxadxmyz/LinkTV/releases/download/v2.1.0/LinkTV-v2.1.0.apk`

## 架构

**v1.x 的做法**：用 WebView 打开央视频官方直播网页，再注入 JS 把网页浮层削掉、只留 `<video>`。这导致一串甩不掉的顽疾——打开要等官网整站加载（电视 Chrome 83 上 20 秒以上）、官网会自己重载把注入层冲掉、确定键在 `NOTREADY` 窗口丢失、官网浮层抢焦点露出原貌。

**v2.0.0 起**：彻底砍掉 WebView 与注入层，改用 **原生 Media3 ExoPlayer** 直接播放直播流。

| | v1.x | v2.x |
|---|---|---|
| 播放 | 浏览器里跑一整个官网网页 | 原生播放器直连 `.m3u8` / `.mp4` |
| 出画面 | 20 秒以上，还会重载 | 1~3 秒 |
| 频道面板 | 注入到别人网页里，可能被冲掉 | 原生绘制，确定键永远弹得出来 |
| 换源 | 曾因自动整页 reload 形成死循环 | 只换 `MediaItem`，索引单调递增 + 硬上限 |

**v2.0.1**：补齐手机触屏与「无数字键」极简遥控器的交互，纯交互层改动，不动播放器、频道表、构建流程。

**v2.1.0**：① 频道表换成**逐条 ffprobe 验证有视频轨**的干净源，剔除 27 条央广网纯音频流（只有声音没画面）与 19 条运营商内网失效源，共 289 频道 / 306 线路；② 画面改为**自动铺满**（按视频宽高比裁切到满屏，保持比例不拉伸、不留黑边），与主流直播 App 一致，无需手动切换。

## 频道表

内置 `assets/tv.m3u`：**306 条线路 / 12 个分类 / 289 个频道**。所有线路都经 ffprobe 验证有**视频轨**（不是只有声音的纯音频流）：

| 分类 | 频道数 | 分类 | 频道数 |
|---|---|---|---|
| 地方频道 | 189 | 央视频道 | 13 |
| 卫视频道 | 21 | 纪录频道 | 26 |
| 电影频道 | 16 | 国际频道 | 9 |
| 4K频道 | 3 | 春晚频道 | 3 |
| 体育频道 | 3 | 儿童频道 | 2 |
| 数字频道 | 2 | 影视回顾 | 2 |

外加第 0 个「我的收藏」分类（动态生成）。

- 同名频道的多条线路合并为**备线数组**，按「m3u8 优先 → https 次之 → rtmp 垫底」排序。
- 清洗 TVBox 私有标记 `$LR•IPV4『线路N』`；`rtmp://` 线路保留在表里但播放器不支持，会自动跳过。
- 播放失败自动切下一条线路，**只换流、不重建页面**，最多 20 次；全部失败就提示并停下，绝不无限重试。
- 后台会静默尝试从 gitee 拉取最新 m3u 存到应用私有目录，**下次启动优先用缓存**；拉取失败或内容异常（少于 100 个频道）一律忽略，继续用内置表，绝不阻塞播放。

## 操作

### 手机 / 触屏

| 操作 | 效果 |
|---|---|
| **点一下画面** | 弹出频道面板（再点面板空白处关闭） |
| 点左侧分类行 | 切到该分类（不关面板） |
| 点右侧频道行 | 立即换到该频道并关闭面板 |
| 点底部「重新加载」 | 重新拉当前频道 |
| 点底部「线路信息」 | 展开/收起线路诊断信息 |
| 左右滑 | 切分类（面板内为移动焦点区） |
| 上下滑 | 换台（面板内为移动光标） |
| 长按画面 / 面板频道行 | 收藏该频道 |

### 遥控器

核心键位只依赖 **方向键 + 确定 + 返回 + 菜单**，极简遥控器（无数字键）也能完整使用。

| 按键 | 面板关闭时 | 面板打开时 |
|---|---|---|
| 确定 | 打开频道/分类面板 | 播放选中频道并关闭（分类栏先进入频道栏；工具栏执行对应工具） |
| 上 / 下 | 本分类内循环换台，**不跨分类** | 移动光标（工具栏内切换两个条目） |
| 左 / 右 | 切到上/下一个分类并播放 | 在 分类栏 → 频道栏 → 工具栏 间移动焦点区 |
| 菜单 | 收藏/取消收藏当前频道 | 收藏/取消收藏光标频道 |
| 返回 | 关闭面板 / 双击退出 | 关闭面板 |
| `0` / `9` | 兼容保留：线路信息 / 重新加载 | 同左（新遥控器不需要，用面板底部工具即可） |

> 旧版把「线路信息」「重新加载」只挂在数字键 `0`/`9` 上，而极简遥控器没有数字键，导致这两个功能用不了。v2.0.1 已把它们搬进**面板底部可点条目**，电视用方向键移入「工具栏」按确定、手机直接点，都不再需要数字键；界面提示文案里也不再出现 `0`/`9`。

收藏提示在右上角临时弹出（2.2 秒消失）。线路信息条随面板自动显隐、默认隐藏，展开后可看当前频道、线路号、播放状态、流地址与频道表统计。

## 画面

- 用原生 `TextureView`（普通 View 层级合成，规避 `SurfaceView` 打洞在部分电视盒子上黑屏）。**画面自动铺满**（cover）：按视频真实宽高比放大裁切到满屏，保持比例不拉伸、不留黑边——16:9 源正好铺满，4:3 等其它比例源自动裁掉超出部分，与主流直播 App 观感一致，无需任何手动设置。
- 声明 `windowLayoutInDisplayCutoutMode=shortEdges`，内容延伸到挖孔/刘海区，消除手机横屏单侧 123px 黑边。
- `usesCleartextTraffic=true` 放行明文 http（源里 194/306 条是 http），`setAllowCrossProtocolRedirects(true)` 支持 http→https 的 302 跳转。
- 强制横屏 `landscape`，黑底启动窗口，首帧渲染后品牌遮罩淡出。

## 构建

由 `.github/workflows/build.yml` 在推送 `main` 时自动构建 debug APK 并发布带版本号的 Release。

- 项目：`android/`（AGP 8.2.2 / Gradle 8.2 / JDK 17 / compileSdk 34 / minSdk 21）
- 依赖：`androidx.media3:media3-exoplayer`、`media3-exoplayer-hls`、`media3-datasource`（均 1.3.1）
- 本地构建：`cd android && ./gradlew assembleDebug`

## 已知限制

- 直播流来自第三方聚合源，**稳定性、清晰度、可用性不受控**，随时可能失效；已用多线路自动切换兜底，但无法保证长期 100% 可用。
- `rtmp://` 协议 ExoPlayer 不支持，这些线路会直接跳过。
- 部分线路是无扩展名的中转脚本（`.php?id=`），先按 progressive 试、失败再强制按 HLS 试，靠自动切线路兜底。
- 在线更新下载的新频道表**下次启动才生效**（当前会话不打断正在播放的内容）。

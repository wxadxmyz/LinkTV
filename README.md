## v1.5.0 修了什么

依据**电视真机（Chrome 83）操作录像**逐帧分析。上一版 v1.4.0 在手机上正常，在电视上暴露两个问题：

| # | 电视上的现象 | 真因 | v1.5.0 修法 |
|---|---|---|---|
| 1 | 打开后 ~20 秒里先露官网原貌（顶部白导航 / 右侧 CCTV 侧栏 / 底部白条），再露一个占满屏的巨大白色播放按钮，最后才出画面 | 官方播放器在电视 WebView 上不自动起播（等一次"用户手势"），老内核还会自己重载一次；v1.4.0 又定死「绝不自动导航 / reload」，只能干等，中间态全被看见 | **新增原生启动遮罩**：不透明品牌页盖住 WebView，网页在底下加载/重载/长浮层一律看不见，只有真出画面才淡出揭开；注入层 `kickPlay()` 主动 `video.play()` + 合成点一次播放按钮把起播提前；`sweepOverlays()` 持续压掉重载后重新长出的浮层 |
| 2 | 按确定键调不出频道列表 | 网页重载窗口里 `__LINKTV_KEY__` 尚未挂载，按键返回 NOTREADY 后被丢弃；官网侧栏还抢走遥控器焦点 | **确定键双保险**：注入层把按键入口提前到脚本最开头、队列放全局 window（跨重注入不丢），boot 后统一消费；原生层 NOTREADY 时把 ok 排队，注入层一就绪立即补发；`ensureUI()` 周期性自愈，网页把 `#ltv-ui` 冲掉也能自动重建 |
| 3 | 左下角自检条常驻碍眼 | v1.4.0 自检条默认显示 | **默认隐藏**，按遥控器 `0` 才显隐；其余反馈改用启动遮罩文字 / 2 秒轻提示，不再强制弹条 |
| 4 | 下载文件名 `LinkTV-debug.apk`，看不出版本 | 构建流程写死文件名 | 版本号唯一来源 `build.gradle`；APK 文件名、Release 标签、下载链接全部带版本号（`LinkTV-v1.5.0.apk`）；旧的无版本号资产自动清理 |

**核心原则不变：绝不自动 loadUrl / 自动切源 / 自动 reload。** 唯一重载入口是用户主动按数字键 9。v1.5.0 只是把"启动期"的可见性从网页手里收归原生层，并主动触发一次起播（不导航）。

## 遥控器操作

| 按键 | 作用 |
|---|---|
| **确定 / OK** | 打开选台面板；面板内选中频道即播放（启动期按下也会排队，注入就绪后自动弹出） |
| ▲ ▼ | 全屏时换台（分类内循环）；面板内选频道 |
| ◀ ▶ | 全屏时换分类；面板内 ◀ 焦点到分类栏、▶ 切分类 |
| 菜单 / ★ | 收藏 / 取消收藏（提示在右上角，2 秒淡出） |
| 返回 / Esc | 收起面板；全屏时连按两次退出 |
| **9** | 手动重新加载当前频道（唯一重载入口；会重新盖上启动遮罩） |
| **0** | 显示 / 隐藏自检条（默认隐藏） |

## 自检条说明

默认**不显示**，按遥控器 `0` 调出，网页全黑也能看见（原生 `TextView`）：

```
LinkTV v1.5.0 · 电视版自检
状态：播放中
网页：www.yangshipin.cn   注入：已就绪 · 清理×21   画面：已出画面
内核：Chrome 83.0.4103.120 | MSE 支持 | WASM 支持
状态正常 · 按 [0] 隐藏/显示自检 · [9] 重新加载
```

- **状态：播放中 / 画面：已出画面** = 正常
- 启动期画面由原生启动遮罩承载（品牌页 + 版本号 + 连接提示），按下 `0` 可叠加查看自检详情
- 若长时间无画面，看遮罩提示；按 **9** 重载；仍不行检查电视网络
- 若 `MSE 不支持` / `WASM 不支持`，是这台电视固件内核能力不足（v1.4.0 已实测 Chrome 83 + MSE/WASM 可正常播放）

## 技术方案

- WebView 全屏打开央视频官方直播页 `https://www.yangshipin.cn/tv/home`，由官方网页负责鉴权 / 拉流 / 播放
- **原生启动遮罩**盖住网页启动期的所有中间态，`PROBE` 连续两次确认出画面或收到 `playing` 上报才淡出揭开
- 注入层 `clean()` 按 DOM 路径隐藏网页浮层，只留 `<video>` 钉成 `fixed` 全屏；`sweepOverlays()` 补压全屏 fixed/absolute 浮层
- 频道表 **CCTV 全系列 18 + 31 省级卫视 = 49 台**，官方 `pid` 直连；换台优先点击页面内频道元素（不刷新），失败降级 `?pid=` 导航（4 秒节流）
- 桌面 UA 用系统真实 Chrome 版本（不虚报）；`dispatchKeyEvent` 前置拦截遥控器按键
- 原生轮询 `PROBE`（出画面 / 清理次数 / 注入阶段 / 内核能力 / 模式 / boot / UI 存活）
- 官方 EPG 节目单，失败降级为「正在直播 · 频道名」
- **不含任何 m3u8 直链，不导入 M3U，不需用户填写任何源**

## 已知限制

- 依赖央视频官方网页，官方改版可能让清浮层 / 换台失效
- 官方播放器需 Chrome 内核 70+（wasm + MSE），过旧会提示
- 异地 / 运营商可能访问不了央视频；按 **9** 可手动重载
- 首次启动仍需等待官方直播拉流（期间显示品牌启动遮罩，而非网页原貌）；主动起播已显著缩短等待
- 换台约需数秒，期间显示品牌待播遮罩
- 各品牌电视 / 盒子的 WebView 存在差异，沙箱无法替代真机实测

# LinkTV v1.3.0 · 电视专用版

> 安卓 TV 直播应用 · 包名 `com.linktv` · 版本 **1.3.0**（`versionCode 4`）
> 仓库：https://github.com/wxadxmyz/LinkTV
> 只含 CCTV 全系列 18 台 + 31 个省级卫视 = **49 个频道**，不含地方台。
> 播放由**央视频官方直播页**负责，安装包内不含任何 m3u8 直链。

---

## 这一版做了什么

v1.2.0 在**手机上能播，电视上不能播**。这一版专门修电视，把根因逐条挖掉：

| # | v1.2.0 的问题 | v1.3.0 的修法 |
|---|---|---|
| 1 | `onPageStarted` 就注入脚本，此刻 `location.hostname` 还是空的，注入层把自己判成 **demo 演示模式**；且 `__LINKTV_BOOTED__` 一开头就锁死 → 清浮层、看门狗全不执行 → 电视上露出央视频官网原貌 + 黑屏 | 只在 `onPageFinished` 注入，由原生明确传 `__LINKTV_MODE__="tv"`，**不再靠网址猜**；ready 标记带模式，误判可被重注入救回 |
| 2 | `screenOrientation="sensorLandscape"` —— **电视没有重力传感器**，系统把 APK 当竖屏手机应用用兼容模式居中显示 → 白色竖块 + 四周大黑边 | 改 `landscape` 硬横屏 + `resizeableActivity=false` + 声明加速度传感器可选 + 启动窗口黑底 |
| 3 | 桌面 UA **虚报 Chrome 120**，电视真实内核远低于此，官方播放器按新能力初始化后崩溃 | 用系统真实 Chrome 版本，取不到用保守下限；改为**实测能力**（MSE / WASM）并在屏幕上显示 |
| 4 | 注入失败**零提示**；20 秒切备用线路写在注入层里，注入没成功就永远不会触发 | 加**原生自检覆盖层**（不依赖网页，全黑也有字）；原生轮询确认注入、未就绪自动重试 8 次；**原生 25 秒看门狗**独立切央视网备用线路 |
| 5 | 手机/电视画面 `object-fit:contain` 四周留黑边 | 改 `cover` 铺满 + 补 viewport meta + WebView 宽视口，画面精确 1920×1080 |

### 装上就能看到状态（不用再猜）

屏幕左下角有原生自检条，**即使网页全黑、注入完全失败也存在**：

```
LinkTV v1.3.0 · 电视版自检
状态：播放中
网页：www.yangshipin.cn   注入：已就绪 · 清理×12   画面：已出画面
内核：Chrome 120.0.0.0 | MSE 支持 | WASM 支持
状态正常 · 按 [0] 隐藏/显示自检
```

- 播放正常后 6 秒淡出成半透明，按遥控器 **数字 0** 随时显示/隐藏
- 卡住时会写明卡在哪：`正在重新初始化…` / `已切换央视网备用线路` / `脚本异常: …` / `网络异常: …`
- 若显示 `MSE 不支持` 或 `WASM 不支持`，说明这台电视的网页内核跑不动央视频播放器 —— 属于固件能力天花板，会自动降级到央视网备用线路

## 遥控器操作

| 按键 | 作用 |
|---|---|
| 打开 App | 直接全屏播放上次频道 |
| 确定 | 呼出选台面板 |
| 面板内 上/下 | 在当前分类内选频道（**不跨分类**） |
| 面板内 左 | 焦点移到左侧频道分类（金色框） |
| 面板内 右 / 分类栏确定 | 切换分类 / 回到频道列表 |
| 全屏时 上/下 | 当前分类内换台 |
| 全屏时 左/右 | 切换分类（央视 ↔ 卫视） |
| 菜单 | 收藏 / 取消收藏（右上角临时提示，2 秒消失） |
| 返回 | 收起面板；连按两次退出 |
| 数字 0 | 显示 / 隐藏自检条 |

OSD（左上角软件名+频道名、右上角分辨率与时间、底部进度条与节目名）3 秒自动隐藏。

## 技术方案

```
MainActivity（原生）
 ├─ 强制横屏 + 硬件加速 + 桌面 UA（真实版本）
 ├─ WebView → https://www.yangshipin.cn/tv/home?pid=…
 ├─ 原生自检覆盖层（TextView，独立于网页）
 ├─ 原生轮询 __LINKTV_DIAG__ → 未就绪重注入（最多 8 次）
 └─ 原生 25s 看门狗 → 无画面切 https://tv.cctv.com/live/<台>/
        ↓ onPageFinished 注入
inject.js（注入层）
 ├─ clean()：清掉官网导航/频道列表/节目单，只留官方 <video> 并钉成全屏
 ├─ LinkTV UI：OSD / 选台面板 / 右上角收藏提示 / 换台遮罩
 ├─ report()：把每个阶段推给原生覆盖层
 └─ __LINKTV_DIAG__()：原生轮询用的自检数据
```

桌面 UA 伪装是必需的：央视频对移动 UA 会 `location.replace` 甩到"下载 App"页。
官方播放器依赖 **wasm + MSE**，需要较新的 WebView 内核；过旧的电视会自动降级到央视网备用线路，并在自检条里写明原因。

## 已知限制（如实说明）

- **依赖官方网页**：央视频改版可能让清浮层或页面内点击换台失效；整页 `?pid=` 导航是兜底
- **电视 WebView 是天花板**：过旧/被裁剪的内核（MSE 或 WASM 缺失）跑不动央视频播放器，此时自动走央视网备用线路，仍可能黑屏 —— 自检条会显示 `MSE 不支持` 让你一眼确认
- **换台有几秒黑屏**：等待官方流重载期间有遮罩与文字状态
- **异地/运营商**可能访问不了央视频，备用线路同样受网络影响
- 沙箱已验证「注入救回 + 清浮层 + 铺满 1920×1080 + 连续换台」，但**各品牌电视/盒子的 WebView 差异仍需真机实测**；装上后按数字 0 看自检条即可定位

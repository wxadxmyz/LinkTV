# LinkTV · 安卓电视直播

**当前版本：v2.0.0（原生播放器版）**

面向 Android TV / 盒子 / 手机的电视直播应用。打开即全屏播放，遥控器操作，无需登录、无需自己填直播源。

> 直播源为第三方聚合流（用户提供的 `muhai-live/tv.m3u`），非官方授权，仅供自用；线路可能失效，应用内已用多备线兜底。

## 下载

- 正式版（带版本号）：`https://github.com/wxadxmyz/LinkTV/releases/download/v2.0.0/LinkTV-v2.0.0.apk`
- 最新构建固定入口：`https://github.com/wxadxmyz/LinkTV/releases/latest`

APK 文件名、Release 标签、下载地址都跟 `android/app/build.gradle` 里的 `versionName` 自动同步，看文件名就知道装的是哪版。

## v2.0.0 架构重写

**v1.x 的做法**：用 WebView 打开央视频官方直播网页，再注入 JS 把网页浮层削掉、只留 `<video>`。这导致一串甩不掉的顽疾——打开要等官网整站加载（电视 Chrome 83 上 20 秒以上）、官网会自己重载把注入层冲掉、确定键在 `NOTREADY` 窗口丢失、官网浮层抢焦点露出原貌。

**v2.0.0 的做法**：彻底砍掉 WebView 与注入层，改用 **原生 Media3 ExoPlayer** 直接播放直播流。

| | v1.x | v2.0.0 |
|---|---|---|
| 播放 | 浏览器里跑一整个官网网页 | 原生播放器直连 `.m3u8` / `.mp4` |
| 出画面 | 20 秒以上，还会重载 | 1~3 秒 |
| 频道面板 | 注入到别人网页里，可能被冲掉 | 原生绘制，确定键永远弹得出来 |
| 按键 | 转发给 JS，未就绪就丢 | `dispatchKeyEvent` 前置拦截，纯原生 |
| 换源 | 曾因自动整页 reload 形成死循环 | 只换 `MediaItem`，索引单调递增 + 硬上限 |

## 频道表

内置 `assets/tv.m3u` 原文，**620 条线路 / 12 个分类 / 404 个频道**，一条不删，全部保留：

| 分类 | 频道数 | 分类 | 频道数 |
|---|---|---|---|
| 央视频道 | 21 | 海外频道 | 1 |
| 卫视频道 | 34 | DJ舞曲 | 21 |
| 省级频道 | 35 | 历届春晚 | 1 |
| 新闻频道 | 60 | 北京地区 | 1 |
| 影视频道 | 6 | 山西地区 | 1 |
| 少儿频道 | 1 | 未分组 | 222 |

外加第 0 个「我的收藏」分类（动态生成）。

- 同名频道的多条线路合并为**备线数组**，按「m3u8 优先 → https 次之 → rtmp 垫底」排序。
- 清洗 TVBox 私有标记 `$LR•IPV4『线路N』`；`rtmp://` 线路保留在表里但播放器不支持，会自动跳过。
- 播放失败自动切下一条线路，**只换流、不重建页面**，最多 20 次；全部失败就提示并停下，绝不无限重试。
- 后台会静默尝试从 gitee 拉取最新 m3u 存到应用私有目录，**下次启动优先用缓存**；拉取失败或内容异常（少于 100 个频道）一律忽略，继续用内置表，绝不阻塞播放。

## 遥控器操作

| 按键 | 面板关闭时 | 面板打开时 |
|---|---|---|
| 确定 | 打开频道/分类面板 | 播放选中频道并关闭（在分类栏时先进入频道栏） |
| 上 / 下 | 本分类内循环换台，**不跨分类** | 移动光标 |
| 左 / 右 | 切到上/下一个分类并播放 | 左=分类栏 / 右=频道栏 |
| 菜单 | 收藏/取消收藏当前频道 | 收藏/取消收藏光标频道 |
| 返回 | 关闭面板 / 双击退出 | 关闭面板 |
| `0` | 显隐信息条（默认隐藏） | 同左 |
| `9` | 重新加载当前频道（切回第一条线路） | 同左 |

收藏提示在右上角临时弹出（2.2 秒消失）。信息条显示当前频道、线路号、状态、地址与频道表统计，按 `0` 查看。

## 画面

- 用原生 `TextureView`（普通 View 层级合成，规避 `SurfaceView` 打洞在部分电视盒子上黑屏），按视频真实宽高比计算 **FIT（contain）**：完整显示、不裁切。16:9 源在电视上正好铺满，在手机超宽屏上两侧留等量黑边，不会再出现「台标被削掉一角」。
- 声明 `windowLayoutInDisplayCutoutMode=shortEdges`，内容延伸到挖孔/刘海区，消除手机横屏单侧 123px 黑边。
- `usesCleartextTraffic=true` 放行明文 http（源里 389/620 条是 http），`setAllowCrossProtocolRedirects(true)` 支持 http→https 的 302 跳转。
- 强制横屏 `landscape`，黑底启动窗口，首帧渲染后品牌遮罩淡出。

## 构建

由 `.github/workflows/build.yml` 在推送 `main` 时自动构建 debug APK 并发布带版本号的 Release。

- 项目：`android/`（AGP 8.2.2 / Gradle 8.2 / JDK 17 / compileSdk 34 / minSdk 21）
- 依赖：`androidx.media3:media3-exoplayer`、`media3-exoplayer-hls`、`media3-datasource`（均 1.3.1）
- 本地构建：`cd android && ./gradlew assembleDebug`

## 已知限制

- 直播流来自第三方聚合源，**稳定性、清晰度、可用性不受控**，随时可能失效；已用多线路自动切换兜底，但无法保证长期 100% 可用。
- `rtmp://` 协议 ExoPlayer 不支持，这些线路会直接跳过。
- 部分线路是无扩展名的中转脚本（`.php?id=`），先按 progressive 试、失败再强制按 HLS 试，靠自动切线路兜底。
- 在线更新下载的新频道表**下次启动才生效**（当前会话不打断正在播放的内容）。
